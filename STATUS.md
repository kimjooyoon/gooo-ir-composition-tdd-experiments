# Preparation checkpoint

This public experiment compares the same 32 corrected Gooo intentions under two settings: one pinned Laya choice, or up to three native attempts with local training-test feedback. There are 64 scheduled intent/setting cells. These repeated settings do not add 64 independent intentions.

The source cohort is already public in [gooo-metaprogramming-experiments](https://github.com/kimjooyoon/gooo-metaprogramming-experiments/tree/main/cohorts/ir-composition-curriculum-2026-09-30/revision-2). Its 96 revised candidates compile and execute, and each declared training suite distinguishes both distractors. The study compiler is source `f3e576ad55796c0d42b2af8b86f874b49baa61d8`, independently validated in [PR 1101](https://github.com/kimjooyoon/meta-ontology-go/pull/1101).

The initial 64-cell mock traversal recorded 85 local mock POSTs and zero Laya inference calls. It is preserved as a superseded preparation. Preparation is expanding to cover every reachable second-choice failure context (128 template roles), and the capture runner is undergoing independent checks for timeout settlement, privacy, source archives and denominators.

Actual Laya capture has not started. Source/proxy/runner bytes and plans will be frozen and published before inference. Model proposals, local corrections, sole-candidate deterministic decisions and postselection evaluation use separate counts. Model weights and environments are shared locally and are not copied into this repository.
